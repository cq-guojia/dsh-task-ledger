# 会话规则注入

## 1. 这个功能是什么

插件把一段规则文案送进 dsh 会话的首轮上下文，让 agent 在用户没有主动提任务时也按台账口径工作；它替代用户手动把同一段文案写进工作区规则文件。功能默认关闭，由用户在插件自己的设置页打开。

边界：只负责 dsh 会话里的这一条消息。不写工作区、不改用户自己的规则文件、不往台账写任何数据、不参与其他 agent 的规则投递。其他 agent 的规则文件位置与 skill 安装见仓库根 `README.md`。

## 2. 入口

- 插件自己的设置页（看板设置页）：标题行右侧的注入开关与状态小字、文案来源标识、文案输入框、保存、恢复默认。
- 两项设置由插件自己读写本机私有文件，与身份文件、台账目录清单同域，不进任何 git 仓库。
- 不使用宿主的插件详情页配置区，不新增 `Config` 字段，不写 profile 的 patch 文档，不碰 localStorage。
- host 半直接读这个文件，不依赖浏览器半在线，也不需要宿主 settings 服务。

## 3. 页面结构

| 区域 | 内容 | 说明 |
|---|---|---|
| 注入开关 | 官方 `Switch`，放核心 `SectionHead` 的右槽 | 默认关；切换即写盘生效，不需要点「保存」；失败回滚并显示错误 |
| 状态小字 | 「已开启自动注入 / 已关闭自动注入」，**可点击** | 点击等同点开关；开启绿色、关闭深灰；切换成功另弹一条提示 |
| 文案来源 | 小图标 + 「默认文案 / 自定义文案」 | 由 host 回执的 `customized` 决定，只反映已保存状态，不跟草稿变 |
| 文案输入框 | 核心 `Textarea` | 显示当前生效的文案；不引编辑器控件、不做预览切换、不做语法高亮 |
| 保存 | 按钮 | 只提交文案，开关不在这里提交；成功弹一条提示 |
| 恢复默认 | 按钮 | 丢弃用户保存的文案，回落到当前界面语言的写死默认文案；**不弹提示** |

## 4. 行为

### 4.1 默认文案

- 程序里写死中文、英文各一段默认文案常量，是「恢复默认」的唯一参照。
- 用户保存的文案另存一份，且**只有一份、不分语言**；写入不覆盖常量，改掉常量会让恢复默认失效。
- 用户值缺省时生效的文案按落盘语言挑对应常量；恢复默认等价于清掉用户值。
- 文案是纯文本：宿主用户消息气泡不解析 Markdown，注入体是一个 text part；界面不做 Markdown 渲染。

### 4.2 注入时机

1. host 半监听 `agent/pre-step`，`await next()` 取得该步的 decision。
2. 只在 decision 为 `enter`、且批次内存在带文本的 `source.kind` 为 `user` 的消息时继续；工具续轮跳过。
3. 在 `decision.messages` 末尾追加一条消息后回传，保留 decision 的其它字段。
4. 消息形状照宿主 V4 会话格式：`role` 为 `user`，`source` 为 producer-owned kind 加 `form` 为 `recall`，带随机 UUID。具体形状与命名以 [dsh-prestep-injection.md](../dependencies/dsh-prestep-injection.md) 为准。

### 4.3 不重复

照同栈规则注入插件的 pre-step 实现，不自加判据：

| 判据 | 要求 |
|---|---|
| 每会话一次 | 按 session id 记已注入标记，命中即原样返回 decision |
| 真人输入 | 无真人输入的续轮不注入 |
| 压缩补回 | 三态判定：能证明块还在 ⇒ 不动；能证明块已消失且曾观测到本块 ⇒ 补一次；事件日志不可读 ⇒ 视为仍在，不补 |
| 事件日志 | 优先 `snapshotEvents()`，旧宿主回退 `events` |

### 4.4 语言

- 界面语言跟随宿主：复用 `isEnglish(t)`（`packages/plugin/src/client/prompts.ts:14-17`）比对自家字典，插件不自备语言开关。
- 注入发生在 host 半，拿不到宿主渲染器的 `t` 席位；所以每个写请求都带当前界面语言，host 把它落盘为 `lang`。
- 注入时 host 读文件里的 `lang` 挑默认文案：中文状态注入中文、英文状态注入英文。用户自定义文案不分语言，切语言不丢、不串。
- 设置页打开时若界面语言与落盘 `lang` 不同，只在语言变化时同步一次；没有常驻监听、没有轮询、不新增注入频次。
- 设置页没打开时切语言，新会话沿用上次的 `lang`，直到下次打开设置页同步。

### 4.5 保存比对

- 保存一律把文案与 `lang` 一起送到 host；比对只在 host 做，默认常量只此一份真源。
- 按**本次请求的语言**比对该语言的默认值，不拿中文默认比英文内容。
- 归一化仅用于比对（CRLF→LF、去首尾空白），不改落盘值。
- 内容与默认值一致（用户没改就点保存、或改回默认值）⇒ 清掉用户值、继续用默认，不落一份与常量相同的副本。
- 只切开关或只同步语言时不带文案，保留原有用户值；开关写请求也不得覆盖正在编辑的草稿。

### 4.6 提示与标识

- 开关切换**写盘成功后**弹一条提示：开启用 `success`（绿）、关闭用 `info`（中性灰）；失败不弹，只回滚开关并显示错误。
- 状态小字常驻显示当前状态、带色（开启 `var(--dtl-success)`、关闭 `var(--dtl-fg-3)`），点击等同切换开关。
- 保存成功仍弹一条提示；**恢复默认不弹提示**。
- 文案来源标识由 host 回执的 `customized`（`stored.text !== null`）驱动：默认态灰勾、自定义态琥珀齿轮。不得用「当前输入框内容 ≠ 默认值」推断 —— 那反映的是未保存草稿。

### 4.7 设置的生效范围

- 保存后的值作用于之后新建的会话首轮；已经打开的会话不追加、不回溯。
- 设置文件读不出来时按默认关处理，不影响会话创建与模型调用。

### 4.8 失败分支

| 场景 | 处理 |
|---|---|
| 设置文件读取失败 | 按默认关处理，落宿主日志，不中断会话 |
| 开关写盘失败 | 界面开关回滚到原状态并显示错误，不弹提示 |
| 事件日志读取抛错 | 按「不可读」处理，不补回 |
| 注入链路其它异常 | 落宿主日志，不中断会话 |

## 5. 状态与边界

| 状态 | 可见 | 可操作 | 说明 |
|---|---|---|---|
| 开关关（默认） | 标题行开关关、小字「已关闭自动注入」深灰 | 编辑文案、点开关或状态小字打开、恢复默认 | 不注入 |
| 开关开 | 标题行开关开、小字「已开启自动注入」绿色 | 编辑文案、点开关或状态小字关闭、保存 | 每个新会话首轮注入一次 |
| 会话已注入 | 无界面状态 | — | 后续轮与续轮不追加 |

硬边界：

- 每会话至多一份文案；token 成本与直接把同一段文本交给宿主规则装配相当，不累积、不随轮次膨胀。提示缓存是否命中未经本项目复核，不作为承诺。
- 注入落在动态区（user 角色的 recall 消息），不是会话开始固定快照的静态指令区；长会话可能随压缩淡出。因此不宣称与规则文件完全等价。
- 不得每轮注入、不得写工作区规则文件、不得引入外部 CLI 或自动安装、不得自创注入机制。
- 设置只放插件自有设置页与自有文件，不放宿主官方配置区；默认文案常量不得被用户值覆盖。
- 文案框保持核心 `Textarea`，不引编辑器、预览切换或语法高亮；状态小字与来源标识只消费 `var(--dtl-*)` token。
- 语言同步不做常驻监听、不新增每轮请求；比对只在 host 做一次字符串比较。
- 注册 skill 与注入常驻文案是两条不同的链路：skill 按需加载，注册它不等于注入提示词。
- 宿主接口一律先读实现本体核实，不得凭方法名猜签名，见 [dsh-prestep-injection.md](../dependencies/dsh-prestep-injection.md)。
