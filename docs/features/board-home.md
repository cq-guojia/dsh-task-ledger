# 看板首页

## 一、入口与三段视图

侧栏条目 + `main` 整页面板。页面内是三段切换的视图：`active`（在办）、`history`（历史）、`settings`（设置）。没有独立浮标入口。

首屏数据一次拿全量：`GET /api/task-ledger/board/snapshot`（统计、在办、趋势、工作区、身份）；历史页趋势与列表分别走 `GET /history/trend`、`GET /history/list`。路由语义见 [host-data-plane.md](../architecture/host-data-plane.md)。

## 二、统计区

- 左侧 8 张统计卡（两行四列），右侧趋势图位；首屏无数据时只画标题与破折号，不填 0 冒充数据。
- 统计台卡显示**结案数**（完成 + 取消），有取消时以小字拆出「完成 X · 取消 Y」。
- 有 `tab` 的卡片可点：点一下把下方列表切到对应档位，并清空其余筛选；无 `tab` 的卡片不伪装可点。
- 8 张统计卡是纯数字块，保持原来的 `Surface` 样式（不用带色条的 `Card`）；悬停底色取核心 `--dshpc-card-hover`。

## 三、趋势图

`TrendChart` 真实渲染：日/周两档切换，周档叠加累计曲线；「只看我的」按当前身份过滤。数字全部来自 skill 的 `stats --trend`，插件不本地推算、不补占位。趋势取不到时不画线，保留已有的完成数。

历史页另有按粒度缓存的趋势与列表数据（`historyByGran`），切换档位时优先用已缓存值，避免闪烁。

## 四、筛选与在办列表

- 左侧菜单七档：`mine` / `all` / `open` / `doing` / `backlog` / `overdue` / `stale`，角标是当前工作区、执行人、搜索范围内的各档计数。
- 工作区、执行人、搜索框、刷新按钮是真实过滤与重新拉取；刷新带 `fresh=1` 清缓存。
- 「我的待办」等分组下的一条条任务行用核心 `Card`：`filled` 自带底色、`hoverable` + `hoverScope: 'card'` 自带悬停变色、状态色条走 `accent`，不再手搓状态条与 `:hover` 背景。
- 列表按工作区分组；单人台账不显示多余分组标题。行内展示任务状态与异常标签，删除的历史行不再混入在办。
- 空态、加载态、错误态各有独立呈现；`degraded` 的工作区标红并保留其他工作区数据。

## 五、任务动作

任务行的写命令动作分为两条链路：

| 动作 | 链路 | 说明 |
|---|---|---|
| 继续 | `POST /task/session/start` | 起会话、不写台账、不登记后台作业 |
| 认领 | `startTask` 后台作业 | `claim:<任务号>`，与其他写动作同一执行体 |
| 完成 | `startTask` 后台作业 | 两种模式共用 `close:<任务号>` key |
| 释放 / 取消 / 删除 | `startTask` 后台作业 | 三个动作各用独立 key，见下表 |

「完成」的两种模式：

| 模式 | 执行者 | 阶段披露 |
|---|---|---|
| 直接结案 | 宿主跑 skill | 真实五阶段：检查 / 拉取 / 写入 / 提交 / 推送 |
| 交给 Agent | DSH agent 在会话里跑 skill | 作业级节点：作业建立 / 正在处理 / 核对台账 / 完成或失败 |

释放 / 取消 / 删除与直接结案共用同一个宿主写命令后台执行体，只是动作、key 与文案不同：

| 动作 | key | 命令 |
|---|---|---|
| 释放 | `release:<任务号>` | `set --release` |
| 取消 | `cancel:<任务号>` | `close --cancel`（带理由） |
| 删除 | `delete:<任务号>` | `delete`（带留言） |
| 删除历史行 | `delete-hist:<任务号>` | `delete --id`（任务号；skill 按 worklog 反查历史行） |

提交即返回，弹窗锁定显示进度：左下 `notice` 与 TaskBar 面板读同一条 `TaskRecord.progress.message`，逐段翻牌；点「后台执行」只收起弹窗、作业照跑。同一任务有任一后台作业在跑时，该行全部动作按钮禁用，防止连点排出队列。终态由核心按动作弹 toast（失败后缀带「请稍后重试」这类人话原因，核心不显示 `TaskRecord.reason`），页面 `onSettled` 按本仓动作前缀刷新看板；只有 Agent 结案挂「查看会话」按钮。点 TaskBar 行按钮后面板默认收起。

历史页删除是同一写动作的第二个入口：删除按钮在对应历史行的 `delete-hist:` 作业运行期间禁用，删除弹窗同样锁定；终态成功后才就地摘行、清月份缓存、刷新统计与趋势，失败保持原行不动、只由 toast 报原因。认领同样走后台作业，成功后由 `onSettled` 刷新快照（归属变了、行要换位置）；「继续」是唯一同步动作。

## 六、边界

- 界面展示的任何计数、时间、状态都来自宿主或自有存储的真实值，禁止占位与模拟。
- 只有用户明确要求做效果展示时才允许 mock，且必须在代码与交付说明里标注。
