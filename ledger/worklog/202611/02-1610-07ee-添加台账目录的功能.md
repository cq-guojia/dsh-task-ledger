## Background

用户 2026-11-03：设置页「添加目录」不要让用户手输路径，**只能选目录**；核心控件（`dsh-plugin-core`）已有选目录能力，直接调，不自己画目录树。

选中目录后的有效判据（两条满足任一）：
1. 选中的目录自己就是台账根（直接含 `ledger/`）；
2. 它的一级子目录里有台账根。

目的：(a) 能直接定位到具体台账目录；(b) 只知道「这个项目有台账」的人选它的直属父目录也算数。

## Process

- `dsh-plugin-core@0.20.6` 才有这条路：`pickWorkspaceFile({ filter: { dirs: true } })`（只能选目录，回绝对路径）+ `serveFsRoute`（host，只读 FS 路由，**不限工作区**）+ `connectFs`（client 接线）。事实与出处见 `docs/design/external/dsh-plugin-core-explorer.md`。
- 0.20.5 打了 tag 但没发到 npm（registry 只有 0.20.4），所以当天先卡住；0.20.6 发出来后依赖从 `^0.20.4` 提到 `^0.20.6`。
- 判据落在 host 侧 `packages/plugin/src/host/services/dirs.service.ts`：先 `addDir(自己)`，`added:false` 才扫一级子目录（`ledgerChildrenOf`，判据 `core/roots.go:35` 同款「直接含 ledger/」），逐个登记；两样都没有就把 skill 的原因原样回前端。
- 父目录本身**不进清单**：skill 读清单时会自愈删掉非台账根（`actions/dirs.go:64-70`）。
- 手输路径的弹窗与 `settingsAddTitle/Hint/Placeholder/Confirm` 四个键一并删掉（改由核心弹窗承担）。
