## Process

- 核心升 0.17.0 → 0.19.1（`packages/plugin/package.json:60`），新 `Modal` 支持 `width` / `height`，弹窗固定尺寸靠它。
- 核心 `Table` **没有隐藏表头的档**：`columns` 仍要传，靠 `tokens.ts` 的 `.dtl-users-table thead{display:none}` 藏掉。
- 「表格顶满」= 抵消核心 `.dshpc-modal__body` 的 `padding:17px 18px`，在 `tokens.ts` 用 `.dtl-users__wrap{margin:-17px -18px}` 写死（核心没开变量）。
- 行间虚线第一版没生效：核心规则是 `.dshpc-table--plain .dshpc-table__row + .dshpc-table__row .dshpc-table__cell`（4 个类），我们同样 4 个类属同权重，核心样式在组件首渲染时才注入、比项目样式晚，于是核心赢。改成 5 个类（多带 `.dtl-users__wrap`）才压住。
- 核心 0.19.1 的 `IconButton` 只有 plain / outline / danger 三档，`danger` **只染图标色**、底色仅在 hover 出现；0.20.0 才加了 `color` / `background` 两个轴（对应 CSS 变量 `--icb-fg` / `--icb-bg`），红底图标按钮现在直接传参即可。
- 核心 0.20.0 的 `.dshpc-modal__foot` 默认带 `border-top`，`footerDivider={false}` 才关 —— 项目自绘的那条线已删。
- 核心 `InputGroup` 是 `display:inline-flex`，`width` 不会自动撑满：宽度得自己给（现在 `style:{width:"360px"}`，靠核心 foot 的 `justify-content:flex-end` 右对齐）。
- 核心 `confirmModal` 是 Promise 式（`true` = 确定），但它自己的 `Translate` 类型与项目 `locales.ts` 的 `Translate` 不兼容，**不能直接 `translate: t`**（会 TS2322），要么不传、要么包一层。
- `tokens.ts` 的 CSS 是模板字符串：注释里写反引号会截断整段样式（本项目 CSS 契约明确禁止反引号 / 反斜杠），本轮踩过一次。
- **分片路径只认名册的 `file`**（2026-11-02）：`core.ShardRel(uuid)` 只该用于「建新分片」。文件可以被手动改名（file 跟着改），也可能来自早期别的命名规则；拿哈希重算会指向不存在的路径 —— `os.Remove` 的 ENOENT 被当成「本来就没有」放过，表现就是 `owners.json` 少了人、分片还在 `owners/` 里。统一走 `actions.ShardRelOf(repo, uuid)`（`scope.go:78`），forget / 锁集 / bootstrap / claim / log / close / set / release / relabel / new / handoff / 建任务查重快照全改。
- **`git diff --cached` 的输出相对仓库根，命令却跑在工作区目录**：台账放在别人仓库的子目录时（`/workspace/Explore`），输出是 `Explore/ledger/owners.json`，拿它当 commit 的 pathspec 就变成 `Explore/Explore/…` ⇒ `did not match any file(s) known to git`。加 `--relative` 拉回当前目录口径（`gitops.go:388`）。
- **删自己不能每本台账各清一次身份**：并发跑时先完成的那本把 `identity.json` 删了，后面几本立刻报「这台机器还没有初始化身份」。改成 `forget --keep-identity`（只摘名册与分片）+ 全部跑完后单独 `logout`。
- **退登录的口径（用户 2026-11-02 拍板）**：**全部删成**才退；任何一本还是 kept（名下有任务）或 failed（报错），本机身份就保住。
- 一次操作**只弹一条** toast：全成绿色；有 kept / failed 合成一条黄或红，正文逐行列出哪本、为什么（曾经成功失败各弹一条，用户看不懂）。
- 身份表的 uuid 只露尾 8 位：36 位硬塞会把整行挤爆；本仓几个测试 uuid 前 30 位相同，取前缀反而分不出，尾段才行。完整值挂 `title`。
