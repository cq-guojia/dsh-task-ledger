## Background

任务号的随机码（4 位 hex）原先在末尾：`YYYYMMDD-HHMM-<slug>-<4hex>`。用户复制短柄（给大模型定位任务）时必须把中文 slug 一起带上，体验差。要求把随机码挪到前面，固定宽度 ASCII 前缀 `YYYYMMDD-HHMM-<4hex>` 在 token 处截止，复制短柄不必碰汉字。同时明确：任务标题就是「做了什么事」，不要在前面加分类 / 类型 / 项目名前缀（之前各 agent 自作主张加了 `skill-`、`盘点-` 之类前缀）。
