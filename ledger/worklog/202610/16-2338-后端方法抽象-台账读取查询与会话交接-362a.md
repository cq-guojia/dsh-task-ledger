### 2026-10-17 定稿清单（用户逐条确认后归档）

**文件布局**（方法与页面严格分家，UI 任务禁止 import host/）：

```
packages/plugin/src/
├── index.ts            # apply 装配（inject workspaceRegistry/webServer → 注册路由），不写业务逻辑
├── host/
│   ├── types.ts        # LedgerWorkspace / TaskRow / HistoryRecord / LedgerFilter 等共享类型
│   ├── script.ts       # runLedgerScript(sub, args, opts)：唯一子进程点，spawn python3 skill 脚本收 JSON
│   ├── workspace.ts    # resolveWorkspaces(registryList)：registry 全量 → 逐个查 ledger/progress.json
│   ├── ledger-read.ts  # readTasks / readHistory / getTask / readWorklog
│   ├── board.ts        # getBoardSnapshot（在办）/ getClosedCounts（--count-only 封顶）/ queryClosed（--months 13 + limit 500）/ getFilterOptions / getCurrentIdentity
│   └── routes.ts       # 薄壳：GET /workspaces /board /tasks /tasks/:ws/:id /history /filters、POST /sessions
├── client/             # 后续 UI 任务专用
└── skill/              # 构建时从 packages/skill 纳入（copy-skill.mjs）
```

**已定决策汇总**：① 解析全包 skill 脚本（TS 零解析，单一真源）；② 身份按工作区取（`git config user.name`，cwd=ws，`--owner` 过滤）；③ 无 watcher / SSE / 轮询，纯按需；④ 未初始化工作区隐藏且后端无此概念；⑤ 工作区来源 = `ctx.workspaceRegistry.list()`（不建配置源）；⑥ 历史有界：统计数行封顶 1 万 + 近 13 个月窗口，列表 limit 500 分页，第 4 卡名「近一年完成」。

**量级实测**（4 核，2026-10-17）：单仓 5 万行全量 1.18s / 30MB；10 仓 × 5 万并行 6.7s / 298MB（不可用）；窗口 + 封顶后首屏 <0.3s。解析约 21μs/行。

**skill 脚本加法式改动**（默认行为不变，独立用户无感）：`history --count-only`（数行封顶 1 万，输出 `{count, capped}`）+ `history --months N`（只读最近 N 个月文件；legacy 平铺文件在窗口模式下不含）。

**动码顺序**：script.ts → workspace.ts → ledger-read.ts → board.ts → routes.ts → index.ts；session.ts / prompts.ts 留到按钮任务（-1 未决）。工程化骨架（tsconfig/cordis.patch/build）随本任务先建——任务 1「插件基础建设」的工程化项因此提前落地，其余项（图标 / 元信息 / 设置页 / 入口槽位注册）不变。
