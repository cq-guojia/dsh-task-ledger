## 背景

skill 部分已用 Go 全部重写，并补进了许多方法。现在要开一个新任务：补齐 DeepSeek harness（DSH）插件仍需要用到的底层调用方法能力。

现状：当前 DSH 插件仍在调用老版 Python 接口，且大多数代码是插件自己写的。因此要对 DSH 插件做重构。

核心逻辑：插件需要读取很多工作区，但 skill 提供的能力是「一个工作区一个工作区读」的。所以 DSH 插件侧负责拿到 DSH 的工作区列表，再针对每个工作区去调用 skill 的底层能力方法拿数据。预期 90% 以上的程序应由核心 skill 的底层能力提供，只有少量特殊、需在 DSH 插件侧自行展现的功能才由插件自己写。

本轮目标（不做实际重构，只做盘点与建议）：
1. 梳理与对比：读 skill 的所有方法，与当前插件功能比较，标出各功能所需底层能力里 skill 已具备 / 尚不具备的。
2. 提供建议：对每个功能给出建议——哪些应放到 skill 里由 skill 开放，哪些应由插件自己写。
